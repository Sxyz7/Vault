# Security Policy

## Supported Versions

Vault is currently in active development and has not yet reached its first public release.

At this time, only the latest development version is supported.

| Version | Supported |
|---------|:---------:|
| Latest Development | ✅ |
| Older Versions | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability in Vault, please **do not disclose it publicly**.

Instead, report it privately by opening a **private security advisory** on GitHub (if enabled) or by contacting the project maintainer directly.

When reporting a vulnerability, please include:

- A detailed description of the issue
- Steps to reproduce the vulnerability
- The affected page or feature
- Any screenshots or proof of concept (if applicable)
- Your browser and operating system

---

## Response Process

Every security report will be reviewed as quickly as possible.

Once a report has been verified, the following steps will generally be taken:

1. Confirm the vulnerability.
2. Investigate the impact.
3. Develop and test a fix.
4. Release the security update.
5. Credit the reporter (if they wish to be acknowledged).

---

## Scope

Examples of security issues include, but are not limited to:

- Authentication vulnerabilities
- Authorization or permission bypasses
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Session management issues
- Sensitive data exposure
- Remote code execution
- File upload vulnerabilities
- Privilege escalation

---

## Out of Scope

The following generally do not qualify as security vulnerabilities:

- Typographical errors
- UI or styling issues
- Feature requests
- General performance improvements
- Duplicate reports of already known issues

---

## Responsible Disclosure

Please allow reasonable time for vulnerabilities to be investigated and resolved before publicly discussing them.

Responsible disclosure helps protect users and allows fixes to be released safely.

---

## Thank You

Thank you for helping keep Vault secure. Responsible security research and reporting are greatly appreciated and help make Vault a safer platform for everyone.
