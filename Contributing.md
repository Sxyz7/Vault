# Contributing

First of all, thank you for your interest in **Vault**! ❤️

Vault is currently in active development and is **not yet open to external code contributions**. At this stage, development is managed solely by the project maintainer to ensure consistency and maintain the project's vision.

## How You Can Help

Although code contributions are not being accepted right now, you can still support the project by:

- 🐛 Reporting bugs or unexpected behavior
- 💡 Suggesting new features or improvements
- 📝 Providing feedback on the user experience
- 🎨 Sharing ideas for collectibles, badges, cosmetics, or events
- ⭐ Starring the repository to follow development

## Reporting Issues

If you encounter a bug or have a suggestion, please open a GitHub Issue and include as much detail as possible, such as:

- A clear description of the issue
- Steps to reproduce the problem
- Expected behavior
- Screenshots (if applicable)
- Browser and operating system information

## Feature Requests

Have an idea for Vault?

Feature requests are always welcome! Before creating a new request, please check the existing issues to avoid duplicates.

When submitting a feature request, consider including:

- A description of the feature
- Why it would improve Vault
- Any examples or mockups (optional)

## Development Status

Vault is currently in the **Alpha** stage of development. Features, designs, and project structure may change frequently as development continues.

## Code Contributions

At this time, pull requests are **not being accepted**.

Once Vault reaches a more stable stage of development, contribution guidelines may be updated to allow community contributions.

## Community

Stay up to date with Vault's development by:

- ⭐ Starring this repository
- 👀 Watching the repository for updates
- 💬 Joining the official Discord server (coming soon)

## Thank You

Your interest, feedback, and support help shape the future of Vault. Thank you for being part of the journey!
